# Security package.
The security package brings the materials a procurement or security team needs
to evaluate a deployment: architecture, data flows, access controls, tenant
boundaries, logging, incident response, retention, availability, and relevant
independent evidence.
Materials are shared according to the requester's role and the approved
disclosure process. A request does not imply a certification or a control that
has not been verified.
