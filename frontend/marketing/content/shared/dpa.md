# Data processing addendum.
Organizations evaluating Aether can request the applicable data processing
addendum, security schedule, subprocessors list, and deployment-specific
processing details.
## Scope to confirm
The final document should identify the parties, processing instructions,
subprocessor controls, security measures, international transfer terms,
deletion and return obligations, audit cooperation, and incident notice path.
This page is a request path, not the executed agreement. Legal terms become
binding only in the approved contract.
