# Integrations are ways into the relationship loop.
Aether can receive evidence through SDKs, APIs, signed webhooks, imports,
commerce and payment systems, analytics, CRM, campaigns, communications,
support systems, and controlled agent or service observations.
## Choose by question
Start with the smallest source set that can answer the first question. Add
connections when the perspective needs more context, not because a catalog is
available. Every source should retain provenance, consent state, tenant scope,
freshness, and failure visibility.
## Connection readiness
For each provider, document the source owner, event contract, replay behavior,
data minimization, identity boundary, and operational owner. Aether should make
missing or unavailable evidence visible instead of silently filling the gap.
