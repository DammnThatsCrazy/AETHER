# REST quickstart.
Use the REST path when a source system can make authenticated HTTP requests but
does not need a dedicated SDK or connector.
Include the approved authentication, tenant, source, event time, provenance,
consent, schema version, and idempotency context. Test both accepted and
rejected payloads, then verify the relationship perspective rather than stopping
at a successful HTTP response.
