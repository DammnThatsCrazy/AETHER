# Events carry evidence; relationships carry meaning.
An event records an observation with a time, source, actor or object context,
tenant scope, provenance, and consent or policy state. It is not automatically
a fact about identity, intent, or outcome.
## Event design
Use stable names, explicit versions, idempotency keys, actor and object
references, source timestamps, ingestion timestamps, and an uncertainty state.
Separate observed values from resolved, inferred, unavailable, or review-
required values.
## From event to perspective
Aether relates compatible observations, preserves the evidence trail, and
surfaces the perspective that is supported. Human-to-human, human-to-agent,
agent-to-agent, and agent-to-human loops use the same governed foundation.
