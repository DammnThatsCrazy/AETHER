# iOS SDK.
The iOS SDK provides a mobile connection path for product, journey, identity,
and outcome observations. It is designed to work beside server events,
commerce systems, support systems, and agent activity.
## Build the loop
Initialize after the app's consent decision, attach deployment and tenant
context, queue observations safely, and confirm delivery from the server-side
ingestion view. Keep credentials and privileged operations off-device.
## Keep the boundary clear
An iOS event is evidence. It becomes useful when Aether can relate it to other
authorized evidence and show the resulting perspective with its uncertainty.
