# Changelog.
The public changelog records changes that can affect implementation, data
contracts, operational behavior, or the perspectives a deployment produces.
## Release discipline
Each entry should state the affected surface, release date, migration action,
compatibility impact, and owner. Breaking changes require a migration note and
a support path. Unreleased notes remain internal until they are approved for
publication.
The live feed is deployment-specific. Confirm the current tenant's release
channel before applying a change.
