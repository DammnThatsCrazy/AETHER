# Web quickstart.
The Web path is the fastest first-party activation for a digital product.
## Activation sequence
1. Add the approved Web SDK package or script.
2. Initialize it with the tenant/site configuration supplied by the deployment.
3. Gate capture on the customer consent policy.
4. Send page, identity, product, commerce, and conversion observations using
   the canonical event contracts.
5. Verify ingestion, provenance, freshness, identity state, and the resulting
   perspective.
Do not place secrets in browser code. Do not treat a successful SDK heartbeat as
proof that every graph relationship or provider is ready.
