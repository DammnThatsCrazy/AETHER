# Start with the connection you already control.
1. Define the first relationship question.
2. Identify where the evidence lives.
3. Choose an SDK, connector, webhook, import, API, or controlled agent path.
4. Preserve tenant, source, consent, time, provenance, freshness, and schema.
5. Send the smallest governed observation.
6. Verify identity, relationship, perspective, and outcome states.
The SDK is one connection path, not the product itself. A complete integration
keeps the evidence explainable from source to relationship to outcome.
