# iOS quickstart.
Install the iOS SDK, configure the deployment endpoint and tenant context,
connect capture to the app consent state, and send the same canonical event
families used by the other first-party paths.
Verify cold start, background/foreground behavior, offline or retry behavior,
identity transitions, consent revocation, and the first server-visible
heartbeat. SDK parity means the resulting evidence can join the same graph
contracts—not that every platform exposes identical device APIs.
