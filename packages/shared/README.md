# @olympuslabs/aether-shared

Shared contracts for the Aether SDKs: the canonical event registry, consent
purposes, ingestion envelope types and SDK version metadata.

You normally don't install this directly. It is a dependency of
`@olympuslabs/aether-web`, `@olympuslabs/aether-server` and
`@olympuslabs/aether-react-native`, which re-export the types you need.
