# Web SDK.
The Web SDK is one connection path into Aether. It helps a product capture
first-party observations with consent, provenance, and tenant boundaries intact.
## What it is for
Use it for page, identity, product, commerce, journey, and conversion evidence
that is created in a browser. Pair it with server events and provider
connectors when the relationship question crosses systems.
## What it is not
The SDK is not the product, a complete identity system, or proof that a
relationship has been resolved. Aether combines SDK observations with other
connections and makes the resulting perspective inspectable.
## Safe implementation
Gate capture on consent, keep secrets server-side, send stable tenant and
session context, and verify freshness and provenance after ingestion.
