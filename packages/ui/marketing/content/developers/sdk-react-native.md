# React Native SDK.
The React Native SDK provides a shared mobile connection path while preserving
the platform-specific consent, lifecycle, and delivery decisions each app must
make.
## Use it with the suite
Send product and journey evidence from the app, then add server-side outcomes,
commerce records, communications, and authorized agent observations. The value
is the connected perspective, not the SDK in isolation.
