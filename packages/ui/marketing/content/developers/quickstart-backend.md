# Backend quickstart.
Use the backend path when the source evidence already exists in services,
commerce systems, payments, workflows, or trusted infrastructure.
## Activation sequence
1. Obtain deployment credentials through the approved server-side path.
2. Configure the Aether API base URL for the target environment.
3. Send tenant-scoped events with source identity, event time, ingestion context,
   schema version, and idempotency keys where applicable.
4. Verify accepted, quarantined, unavailable, and rejected states.
5. Inspect the relationship and outcome perspective created from the evidence.
Keep credentials server-side. Validate missing, stale, conflicting, revoked,
and duplicate evidence explicitly.
