# Android SDK.
The Android SDK is a first-party mobile connection for observations created in
an Android experience. It supports a broader relationship loop that can also
include APIs, imports, communications, commerce, and agent events.
## Implementation principles
Apply consent before capture, use the deployment's tenant configuration, avoid
secrets in the client, and validate event provenance, freshness, and delivery
before relying on a perspective.
