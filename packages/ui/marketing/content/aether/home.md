# Connect the systems. See the relationships.
Aether connects where humans, agents, organizations, and value flows create
evidence—then turns that evidence into governed relationships, perspectives,
and observable outcomes.
**Primary CTA:** Explore connections
**Secondary CTA:** Start a pilot
## The SDK is one path. The relationship layer is the value.
Aether is a suite of connection paths and intelligence surfaces. It can receive
first-party application observations, business-system data, campaigns,
communications, social sources, commerce, payments, APIs, webhooks, imports,
and agent events.
The connection method answers where evidence came from. Aether's value appears
when that evidence retains its context, joins the right relationships, and
creates a perspective that can be reviewed and connected to an outcome.
## Start with the connection you already control
- **First-party applications:** Web, iOS, Android, and React Native SDKs.
- **Business systems:** commerce, payments, CRM, analytics, support, campaigns,
  communications, and workflow systems.
- **External sources:** social, community, partner, identity, market, and
  protocol sources when authorized and enabled.
- **Direct paths:** signed webhooks, imports, event APIs, and controlled agent
  or service observations.
Choose the minimum source set needed to answer the first relationship question.
Expand only when the next source adds context that changes the perspective.
## Four loops, one relationship layer
### Human to human
Understand collaboration, communication, shared journeys, approvals, and the
context that moves between people.
### Human to agent
Preserve delegation, instructions, recommendations, review, and approval so an
agent's work remains connected to the authority that shaped it.
### Agent to agent
Follow orchestration, service use, dependencies, handoffs, and economic or
operational relationships among agents and services.
### Agent to human
Make notifications, recommendations, escalations, decisions, and handoffs
visible as part of the same loop.
## From evidence to perspective
1. Connect the sources that contain the evidence.
2. Preserve source, tenant, consent, freshness, provenance, and quality.
3. Resolve identities, entities, journeys, episodes, campaigns,
   communications, and outcomes when supported by evidence.
4. Create a perspective that shows what is known, uncertain, missing, and
   review-required.
5. Review, approve, deliver, and observe what changed afterward.
