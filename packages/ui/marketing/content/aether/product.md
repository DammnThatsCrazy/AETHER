# A relationship intelligence layer for connected systems.
Aether connects the places where people, agents, systems, and value flows create
evidence, then preserves the relationships and perspectives that evidence makes
possible.
## Start with connections
Aether receives evidence through Web, iOS, Android, and React Native SDKs;
commerce, payment, analytics, CRM, campaign, communication, and support
connectors; signed webhooks; imports; event APIs; and controlled agent or
service observations.
No single connection method is the product. Choose the minimum source set that
can answer the first relationship question, then expand as the perspective
proves useful.
## End with relationships and perspectives
Aether can preserve or resolve identities, relationships, journeys, episodes,
campaign touchpoints, communications, decisions, actions, and outcomes when
the evidence supports them.
The resulting perspective can cover people and organizations, human-to-human
interactions, human-to-agent delegation, agent-to-agent coordination, and
agent-to-human recommendations or handoffs.
## The first commercial package
The Revenue Intelligence Graph is the first commercial package for connecting
customer, commerce, campaign, communication, journey, attribution, and outcome
evidence. It is an entry path into the broader platform—not the definition of
Aether.
