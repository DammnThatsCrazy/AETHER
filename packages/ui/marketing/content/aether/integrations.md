# Connect the systems where the relationship happens.
Aether connects applications, commerce, campaigns, communications, social
systems, analytics, support, APIs, imports, and authorized agent activity.
## Connect by evidence
Start from the question, then select the sources that can answer it. A campaign
connector, communication stream, or SDK is useful only when it contributes
evidence to a relationship perspective.
## Connect by responsibility
Every source has an owner, contract, consent boundary, freshness expectation,
and failure mode. Aether keeps those conditions visible while the loop moves
from human to human, human to agent, agent to agent, and agent to human.
