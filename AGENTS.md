# AETHER Agent Instructions

Before opening or updating a PR:

1. Run `make repo-doctor-fix`.
2. Run `make ci-check`.
3. Commit all generated docs and sync outputs.
4. Do not hand-edit generated docs.
5. Do not bypass TypeScript/package export failures.
6. If backend routes, schemas, contracts, SDK public types, Profile 360, or Kyber surfaces changed, update the required ownership-map surfaces.
7. PR is not complete until `make ci-check` exits 0.

Generated documentation ownership:

- `docs/_generated/` is generated by `python scripts/docs_extract/run_all.py`.
- `docs/REPO-INDEX.md` and `docs/AUTOMATION.md` are generated by `python scripts/sync_docs.py`.
- Source-linked authored docs may only receive `last_synced_commit` stamps after the linked source was reviewed.
