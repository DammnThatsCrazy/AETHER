# Cutover inventory

This is the initial disposition of overlapping runtime and repository paths at
`Development` `17503aef9`. It records decisions **before** path moves or
retirement. A `merge` disposition means converge behavior under the named
authority after parity proof; it is not permission to delete the old path.
The [proof ledger](proof-ledger.md) records actual cutover evidence and dates.
