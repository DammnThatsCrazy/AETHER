# Lenses

## Overview

Lenses are interpretive views over graph state. Unlike 360 surfaces
which are entity-centric, lenses provide cross-entity analytical
views filtered by a specific dimension.

## Available Lenses

| Lens | Dimension | Description |
|---|---|---|
| Journeys | Journey stage | Cross-device journey analytics |
| Value | Monetary flow | Revenue and economic analysis |
| Risk | Risk signals | Anomaly and risk detection |
| Signals | Event stream | Real-time event monitoring |
| Syndicates | Entity groups | Segmentation and cohort analysis |

## Lenses vs. 360s

- **360s** answer "tell me everything about this entity."
- **Lenses** answer "show me this dimension across all entities."
