# Value

Value tracking in Aether covers monetary and non-monetary value
attribution across entities, campaigns, and journeys.

## Core Invariant

Missing, empty, and zero are distinct states. Value display uses
canonical `ValueDisplay` / `formatUSD` paths. FX conversion is
handled at the canonical value/FX path.
