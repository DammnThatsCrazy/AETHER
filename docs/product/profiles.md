# Profiles

## Overview

Profiles are entity-centric intelligence summaries within the Aether
intelligence graph. A profile aggregates all known observations,
relationships, and derived intelligence for a single entity.

## Entity Types

| Type | Description |
|---|---|
| Person | Individual human entity |
| Organization | Business or organizational entity |
| AI Agent | Autonomous agent entity |
| Protocol | On-chain protocol entity |

## Profile Intelligence

Each profile surfaces:

- Identity resolution state
- Activity timeline
- Value summary (LTV, revenue)
- Journey progression
- Campaign touchpoints
- Communication history
- Risk signals
- Agent interactions
