# UI Label Map

## Overview

The UI label map defines the canonical labels used in Aether and Kyber
user interfaces. All UI text must reference this map to ensure
consistent terminology.

## Navigation Labels

| Location | Label | Notes |
|---|---|---|
| Main nav | Profiles | Entity-centric 360 view |
| Main nav | Journeys | Journey stage and touchpoint view |
| Main nav | Campaigns | Campaign performance and attribution |
| Main nav | Agents | Agent lifecycle and monitoring |
| Main nav | Communications | Outbound messaging and delivery |
| Main nav | Value | Monetary and non-monetary value |
| Main nav | Signals | Event stream and alerting |
| Main nav | Syndicates | Entity grouping and segmentation |
| Main nav | Lenses | Interpretive graph views |

## 360 Surface Labels

| Surface | Header | Subtitle |
|---|---|---|
