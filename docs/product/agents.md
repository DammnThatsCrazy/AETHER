# Agents

Agents are autonomous or semi-autonomous entities that act on
intelligence graph state. Agent actions are observations that
re-enter the ingestion pipeline.

## Agent Lifecycle

```
defined → configured → activated → running → paused → deactivated
```

## Governance

Agent actions are governed by consent-scoped execution boundaries
and model governance gates.
