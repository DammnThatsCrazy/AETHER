# Aether Service Status
This page is the public status entry point for service availability, incidents,
maintenance, and component health.
Service availability is separate from provider or feature readiness. A service
can be available while a tenant's selected connector, SDK fleet, feature flag,
or deployment dependency is gated or unavailable.
The production status page should be backed by the deployment's monitored health
checks and incident process. Until that service is connected, contact the
operator through the support or procurement path for deployment-specific state.
