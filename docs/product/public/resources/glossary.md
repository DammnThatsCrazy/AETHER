# Aether Public Glossary
## Connection
A path by which evidence enters Aether: SDK, connector, API, import, webhook,
or controlled agent/service observation.
## Relationship
A supported link among entities, events, journeys, systems, or actors. A
relationship carries evidence and a state; it is not automatically certainty.
## Perspective
A governed view created from connected evidence and relationships. A perspective
explains what can be seen, what is uncertain, and what decision or workflow may
follow.
## Observation
An event or record received from a source. An observation is not the same as an
inferred identity, causal explanation, or approved action.
## Human-to-agent loop
The relationship context in which a person delegates, instructs, reviews, or
approves an agent's work.
## Agent-to-agent loop
The relationship context in which agents coordinate, call services, exchange
work, or depend on one another.
## Agent-to-human loop
The relationship context in which an agent recommends, notifies, escalates, or
hands work back to a person.
## Revenue Intelligence Graph
Aether's initial commercial package for connecting customer, commerce, campaign,
communication, journey, attribution, and outcome evidence. It is an entry point
into the broader relationship intelligence platform.
