# Aether React Native SDK

The Aether React Native SDK is a thin observation client that captures observations from React Native applications.

## Installation

```bash
npm install @aether/react-native
```

## Capabilities

- Screen view tracking
- Custom event emission
- Session lifecycle management
- Identity hints
- Batch sending to `/v1/batch`
- Offline spooling
- Idempotent retry
- Privacy controls
- Heartbeat emission
- Debug mode
- App lifecycle events (background, foreground)
