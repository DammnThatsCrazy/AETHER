# Aether Android SDK

The Aether Android SDK is a thin observation client that captures observations from Android applications.

## Installation

```gradle
implementation 'com.aether:sdk-android:0.1.0-alpha.0'
```

## Capabilities

- Screen view tracking
- Custom event emission
- Session lifecycle management
- Identity hints
- Batch sending to `/v1/batch`
- Offline spooling
- Idempotent retry
- Privacy controls
- Heartbeat emission
- Debug mode
- App lifecycle events
