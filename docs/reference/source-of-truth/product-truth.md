# Product Truth

Aether is a contract-governed intelligence graph and runtime platform.

It helps tenants understand people, agents, journeys, campaigns, communications, value flows, risks, and system events across their applications and connected providers.

## Product Surfaces

- Aether Console
- Kyber Operator Console
- Noesis intelligence surfaces
- Developer portal
- SDKs
- Provider and connector workflows
- API access
- MCP access
- Future CLI access

## Core Product Concepts

| Concept | Meaning |
|---|---|
| Profile | Human, account, organization, or entity-level graph identity |
| Agent | Autonomous or assisted system actor |
| Journey | Ordered path of events, touches, communications, and outcomes |
| Episode | Bounded sequence of related activity |
| Campaign | Resolved marketing or activation initiative |
| Communication | Message, email, notification, reply, thread, or campaign interaction |
| Signal | Meaningful observed behavior or inferred indicator |
| Syndicate | Reusable grouping of entities around shared traits, behavior, or value |
| Value | Financial, operational, conversion, or business impact |
| Risk | Compliance, trust, anomaly, security, or failure exposure |
| Lens | View that interprets graph state for a specific use case |
| 360 | Product surface that provides a complete view around one entity or domain |
