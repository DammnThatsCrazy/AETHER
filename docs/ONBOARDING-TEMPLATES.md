# Onboarding Templates

Package templates define default implementation steps, success criteria, recommended playbooks, integrations, and audit exports.

## Templates

1. Revenue Intelligence Graph: SDK install, commerce mapping, Profile360, retention/expansion recommendations, outcome ledger, playbooks, CRM/marketing integration, outcomes, and value review.
2. Fraud & Risk Intelligence Graph: events, entity mapping, graph traversal, fraud recommendations, investigation workspace, fraud playbook, review queue integration, audit exports, and avoided-loss outcomes.
3. Agent Governance Graph: agent event capture, agent identity mapping, H2A/A2H/A2A relationships, governance recommendations, approvals, failure playbooks, action dispatch, audit exports, and agent outcomes.
4. Operational Decision Intelligence: OODA, recommendations, decision records, action logging, outcome feedback, playbooks, integrations, ledger, and value review.
5. Program Integrity Graph Planning: use case, entity/case schema, audit requirements, HITL policy, investigations, decision audit, outcomes, and deployment readiness.
6. Critical Infrastructure Coordination Graph Planning: dependency entities, operational events, incident/action workflows, playbooks, audit exports, readiness, and tabletop/pilot criteria.
