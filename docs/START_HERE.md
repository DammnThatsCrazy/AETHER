# Start Here

Welcome to the Aether repository.

Aether is a contract-governed intelligence graph and runtime platform that captures observations from SDKs, providers, and connectors; normalizes them into canonical contracts; projects them into a tenant-scoped intelligence graph; and surfaces Profiles, Agents, Journeys, Communications, Campaigns, Value, Risk, Signals, Syndicates, and Lenses through product, operator, developer, and intelligence interfaces.

## Current Status

Aether is currently a pre-production private alpha at version `0.1.0-alpha.0`.
