# Entity Model

The canonical entity model unifies Web2, Web3, and hybrid companies under one
set of concepts. Entities are referenced in events via `EntityRef` from
`packages/shared/entities.ts`.

## Core (always present)

| Entity | Meaning |
|---|---|
| **Tenant** | Top-level customer of Aether (one per API key) |
| **Org** | Business account inside a tenant (B2B / multi-tenant apps) |
| **User** | End user, identified by `user_id` post-login |
| **Session** | One continuous interaction window |
| **Device** | Physical/logical device fingerprint |
| **Application** | Host app/product emitting events |

## Access plane

| Entity | Meaning |
|---|---|
| **Resource** | Anything access-controlled: page, feature, API, file, bot |
| **Approval** | Request + decision for gated access or payment |
| **Entitlement** | Durable grant of access to a Resource |

## Commerce plane

| Entity | Meaning |
|---|---|
| **Plan** | Pricing tier / catalog item |
| **Subscription** | Recurring plan binding |
| **Invoice** | Billing document |
| **Payment** | Single value-transfer event, rail-agnostic |

## Web3 plane (optional)

| Entity | Meaning |
|---|---|
| **Wallet** | On-chain address, scoped by `VMType` + `chainId` |
| **Contract** | Deployed smart contract |
| **Chain** | Blockchain network |
| **Token** | ERC20/SPL/BRC20/etc. asset |
| **Protocol** | Higher-order DeFi/infra product |

## Agent plane (optional)

| Entity | Meaning |
|---|---|
| **Agent** | Autonomous worker acting on behalf of user/org |
| **Service** | Callable endpoint agents consume (incl. x402) |

## Actor kinds

Every event may carry `provenance.actor_kind`:
`human | org | wallet | agent | service | system`.

This is how Web2 users, Web3 wallets, and agents share the same event shape
without leaking assumptions.

## Rails

`payment_*` events carry a `rail` field:
`fiat | stripe | invoice | onchain | x402 | internal_credit`.

Use rails to avoid "Web3 payment" vs "Web2 payment" bifurcation. A hybrid
company can emit `payment_completed` with `rail: 'stripe'` for fiat checkouts
and `rail: 'x402'` for agentic purchases, from the same codepath.

## Agentic Observability Entity Types

> These entities are observed and tracked by AETHER. AETHER never owns, controls,
> or executes through these entities. All entity instances carry `execution_by_aether: false`.

### Agentic observation (7 types)

| Entity | Description |
|---|---|
| `ExternalAgent` | An AI agent running on an external platform, observed by AETHER |
| `AgentConnection` | A connection between an agent and an external platform/service |
| `MCPConnection` | A Model Context Protocol server connection observed from an agent |
| `AgentTool` | A tool available via MCP or external API, observed |
| `AgentPermissionSet` | Permission scopes granted to an agent on an external platform |
| `AgentActivity` | A unit of agent activity observed from an external source |
| `AgentRiskSignal` | A risk signal produced by AETHER from observed agent activity |

### Robinhood-style external account observation (13 types)

| Entity | Description |
|---|---|
| `ExternalAgenticAccount` | An external account linked to and controlled by an AI agent (e.g., Robinhood agentic account) |
| `ExternalBrokerageAccount` | An external brokerage account observed via API/webhook |
| `AgentBudgetObserved` | Agent budget state observed from external platform |
| `TradingStrategyObserved` | A trading strategy configured externally and observed |
| `TradeIntentObserved` | A trade intent generated by an agent, observed before external execution |
| `TradeOrderObserved` | A trade order observed after external execution |
| `TradeFillObserved` | A trade fill observed from external platform |
| `TradeRejectionObserved` | A trade rejection observed from external platform |
| `PortfolioSnapshotObserved` | A portfolio state snapshot observed from external platform |
| `PositionSnapshotObserved` | A position snapshot observed from external platform |
| `AgentPerformanceSnapshotObserved` | Agent trading performance metrics observed |
| `AgentDisconnectObserved` | An agent account disconnect event observed |
| `AgentNotificationObserved` | A notification to the agent observed from external platform |

### AgentMail-style communication observation (13 types)

| Entity | Description |
|---|---|
| `AgentInboxObserved` | An agent inbox observed from an email/communication provider |
| `AgentEmailAddressObserved` | An email address assigned to an agent, observed |
| `AgentThreadObserved` | A message thread in an agent inbox, observed |
| `AgentMessageObserved` | A message in an agent thread, observed |
| `AgentAttachmentObserved` | An attachment in an agent message, observed |
| `ExtractedEntityObserved` | An entity extracted from a message or attachment |
| `OTPObservation` | A one-time password detected in a message |
| `InvoiceObservation` | An invoice detected in a message or attachment |
| `ReceiptObservation` | A receipt detected in a message or attachment |
| `CalendarIntentObserved` | A calendar/scheduling intent detected in a message |
| `SupportRoutingObserved` | A support routing decision for a message, observed |
| `MessageProviderObserved` | An external message provider observed |
| `CustomDomainObserved` | A custom email domain configured for an agent inbox, observed |

### x402/protocol observation (11 types)

| Entity | Description |
|---|---|
| `X402InteractionObserved` | A complete x402 protocol interaction, observed end-to-end |
| `X402ChallengeObserved` | An HTTP 402 challenge response observed |
| `X402PaymentRequirementObserved` | Payment requirement metadata from PAYMENT-REQUIRED header |
| `X402SignatureObserved` | A payment signature submitted externally, observed |
| `X402FacilitatorObserved` | An x402 facilitator observed in a protocol interaction |
| `X402VerificationObserved` | A verification result observed from a facilitator |
| `X402SettlementObserved` | A settlement event observed (executed externally, not by AETHER) |
| `X402ResourceAccessObserved` | A resource access outcome observed |
| `PaidResourceObserved` | A paid resource observed in an x402 interaction |
| `ResourceProviderObserved` | A resource provider observed |
| `ProtocolProviderObserved` | A protocol/facilitator provider observed |
