# Release Truth

Aether has not reached public production release.

The first canonical repo baseline is:

`0.1.0-alpha.0`

## Version Policy

Aether uses SemVer.

Before public production, every version must use a pre-release suffix:

- `alpha`
- `beta`
- `rc`

Examples:

- `0.1.0-alpha.0`
- `0.2.0-alpha.0`
- `0.5.0-beta.0`
- `1.0.0-rc.0`

## Release Truth Rule

Do not describe any version as:

- stable
- production
- GA
- enterprise-ready
- public release

unless Aether has actually reached that state.

## Internal Milestones

Historical internal work should be documented as retrospective milestones, not fake public releases.
