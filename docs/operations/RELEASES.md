# Aether Releases

Aether is currently pre-production.

The first canonical repo baseline is:

`0.1.0-alpha.0`

## Release Classes

| Class | Meaning |
|---|---|
| `alpha` | Internal or design-partner candidate. APIs and contracts may still change. |
| `beta` | Feature-complete candidate with known stabilization work. |
| `rc` | Release candidate. Intended to become stable unless blockers appear. |
| `1.0.0` | First public production release. |
