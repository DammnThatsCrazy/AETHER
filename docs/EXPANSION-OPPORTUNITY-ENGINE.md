# Expansion Opportunity Engine

The Expansion Opportunity Engine identifies package, module, integration, deployment, services, audit export, enterprise, and government-planning motions from observed customer value and adoption.

## Logic

Inputs include observed and pending value, outcome capture, playbook ROI, integration adoption, package fit, recommendation-family depth, and usage growth. High observed value with healthy capture creates enterprise-upgrade motions; integration gaps with sufficient value create integration-expansion motions.

## Safe commercial claims

Opportunities are recommendations for Olympus Labs operators. They are not revenue guarantees. Estimated revenue potential is a planning estimate derived from observed value and packaging assumptions.

## Visibility

Kyber sees tenant-level opportunity summaries. Tenant-facing Value Review does not expose sales scoring internals.
