# Aether iOS SDK

The Aether iOS SDK captures observations from iOS applications.

## Installation

Swift Package Manager:

```swift
.package(url: "https://github.com/DammnThatsCrazy/aether-ios-sdk", from: "0.1.0-alpha.0")
```

## Capabilities

- Screen view tracking
- Custom event emission
- Session lifecycle management
- Identity hints
- Batch sending to `/v1/batch`
- Offline spooling
- Idempotent retry
- Privacy controls
- Heartbeat emission
- Debug mode
- App lifecycle events
