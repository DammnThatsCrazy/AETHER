# Perspectives and Relationships
Aether does not stop at collecting events. It preserves the relationships that
make evidence useful and creates perspectives that remain tied to their source,
confidence, freshness, and boundaries.
## Four relationship loops
| Loop | What Aether can help explain |
| --- | --- |
| Human → human | collaboration, communication, shared journeys, and approvals |
| Human → agent | delegation, instructions, recommendations, and review |
| Agent → agent | orchestration, service use, dependencies, and handoffs |
| Agent → human | notifications, recommendations, escalations, and decisions |
## A perspective is not a fact claim
Aether distinguishes an observed source record from a resolved relationship,
an inference, a recommendation, an approval, and an outcome. Missing evidence
is not silently treated as zero activity. Uncertainty remains visible so that a
person can decide what to trust and what to investigate next.
## From perspective to outcome
The loop closes when a perspective can be reviewed, an action can be approved or
delivered, and the result can be observed afterward. This is why connections,
communications, campaigns, and SDKs matter: they make the relationship loop
observable from start to finish.
