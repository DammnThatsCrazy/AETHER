# Aether Developers
Build the connection layer that lets Aether understand the relationships inside
your systems.
## Start with the connection you already control
Use the Web, iOS, Android, or React Native SDK when you need first-party
application observations. Use a connector, webhook, import, or API when the
evidence already lives in another system. Most real deployments use a suite of
paths rather than one integration method.
## Recommended path
1. Read [Connections and Integrations](/doc/product/connections).
2. Choose the smallest source set needed for the first relationship question.
3. Follow the [Web activation guide](/doc/quickstart/web-sdk) or the matching SDK guide.
4. Review the event, consent, identity, and relationship contracts.
5. Verify the resulting perspectives, provenance, quality, and outcomes.
