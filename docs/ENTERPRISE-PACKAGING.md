# Enterprise Packaging

Enterprise packaging makes Aether commercially legible without adding a separate product layer. Packages map existing modules to buyer personas, use cases, audit needs, deployment modes, pricing levers, tenant demand, and next actions.

## Implemented

- Shared TypeScript and backend Pydantic contracts.
- Six initial solution package definitions.
- Package readiness reports.
- Tenant-package fit scoring from usage metrics.
- Kyber pages for package list/detail and deployment readiness.
- Tenant-facing Aether Audit Exports page.

## Pricing levers

Packages expose pricing levers such as operator seats, tracked entities, recommendations, playbook runs, dispatches, audit retention, observed value, avoided loss, premium connectors, and readiness assessments.

## Known gaps

Enterprise-isolated and regulated modes need customer-specific runbooks and control evidence before higher readiness labels. Self-hosting is future work.
