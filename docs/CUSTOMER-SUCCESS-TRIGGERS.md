# Customer Success Triggers

Customer success triggers identify onboarding stalls, value proof, and expansion readiness.

## Trigger Types

`sdk_stalled`, `event_mapping_stalled`, `graph_not_activating`, `recommendations_not_viewed`, `decisions_not_recorded`, `actions_not_logged`, `outcomes_not_captured`, `playbooks_unused`, `integrations_failed`, `value_proven`, and `expansion_ready`.

Each trigger includes severity, reason, supporting metrics, and recommended Olympus action. Triggers are generated from implementation plan scores, checklist progress, blockers, and rollout telemetry.

## Rollout Notes

Start with generated operational triggers in Kyber, then connect live telemetry for recommendation views, decisions, actions, outcomes, playbook runs, and integration failures.
