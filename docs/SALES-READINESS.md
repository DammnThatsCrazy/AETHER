# Sales Readiness

Sales readiness aggregates solution packages, GTM collateral, buyer personas, ROI calculators, audit export support, and deployment readiness.

## Dashboard checks
- Packages ready to sell.
- Packages missing collateral.
- Packages missing ROI calculators.
- Packages missing audit export support.
- Packages missing deployment readiness.
- Recommended next sales actions.

## Enterprise vs regulated vs government-planning language
- Enterprise: package readiness, tenant isolation, audit exports, integration governance.
- Regulated: planning for stronger controls and evidence; no certification claims unless independently implemented.
- Government planning: future public-sector readiness only; no FedRAMP, StateRAMP, ATO, classified workload, or certified government cloud claim.
