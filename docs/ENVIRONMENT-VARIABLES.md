# Environment Variables

All backend config is environment-driven (`config/settings.py`, frozen
dataclasses with `_env*` helpers). Frontends use `VITE_*` vars. Nothing
optional is required for local startup unless its feature flag is enabled.

## Example files

| File | Purpose |
| --- | --- |
| `.env.example` | Canonical reference — every backend var `settings.py` reads (CI checks coverage) |
| `.env.local.example` | Local dev: in-memory stores, MSW frontends, no external services |
| `.env.staging.example` | Staging: real DB/cache/queue + required secrets |
| `.env.production.example` | Production: required secrets + secret-manager refs, flags safe |
| `frontend/aether/.env.example` | Aether `VITE_*` (`VITE_AETHER_ENV`, `VITE_API_BASE_URL`, Auth0/OIDC, Stripe publishable) |
| `frontend/kyber/.env.example` | Kyber `VITE_*` (`VITE_KYBER_ENV`, `VITE_API_BASE_URL`, feature flags) |

## Required by environment

- **local**: `AETHER_ENV=local` only. (Backend runs fully in-memory.)
- **staging/production**: `JWT_SECRET`, `DATABASE_URL` (the app fails fast if
  missing), plus `BYOK_ENCRYPTION_KEY`, `ORACLE_SIGNER_PRIVATE_KEY`,
  `GRAFANA_ADMIN_PASSWORD` where those features are used.

## Feature-flagged / optional groups (default off)

Data quality (`AETHER_DATA_QUALITY_ENABLED`, `KYBER_INTELLIGENCE_QUALITY_ENABLED`),
external billing (`AETHER_EXTERNAL_BILLING_ENABLED`, `AETHER_STRIPE_BILLING_ENABLED`,
`KYBER_BILLING_PROVIDER_SYNC_ENABLED`, `BILLING_PROVIDER_MODE`), intelligence-graph
layers (`IG_*`), CIS (`CIS_ENABLED`), partner future flags
(`AETHER_PARTNER_ECOSYSTEM_ENABLED`, …), and (upcoming) connector flags
(`AETHER_CONNECTOR_*_ENABLED`) and demo (`DEMO_MODE`, `AETHER_DEMO_SEED_ENABLED`).
Their provider env vars (Stripe keys, connector credentials) are required **only
when the flag is on**.

## Frontend env modes

`VITE_AETHER_ENV` / `VITE_KYBER_ENV` / `VITE_DEMO_ENV` ∈
`local-mocked | local-live | staging | production`. `local-mocked` starts MSW
and requires no backend. Deployment uses env-driven `VITE_API_BASE_URL` — never
hardcode `localhost`.

The generated `docs/_generated/env.json` is the machine-readable index of
backend vars (regenerated by `make extract-docs`). See
[Secrets Management](SECRETS-MANAGEMENT.md) and
[Local Development](LOCAL-DEVELOPMENT.md).
