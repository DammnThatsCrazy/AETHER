# Environment Variables

All backend config is environment-driven (`config/settings.py`, frozen
dataclasses with `_env*` helpers). Frontends use `VITE_*` vars. Nothing
optional is required for local startup unless its feature flag is enabled.

## Example files

| File | Purpose |
| --- | --- |
| `.env.example` | Canonical reference — every backend var `settings.py` reads (CI checks coverage) |
| `.env.local.example` | Local dev: in-memory stores, MSW frontends, no external services |
| `.env.staging.example` | Staging: real DB/cache/queue + required secrets |
| `.env.production.example` | Production: required secrets + secret-manager refs, flags safe |
| `frontend/aether/.env.example` | Aether `VITE_*` (`VITE_AETHER_ENV`, `VITE_API_BASE_URL`, Auth0/OIDC, Stripe publishable) |
| `frontend/kyber/.env.example` | Kyber `VITE_*` (`VITE_KYBER_ENV`, `VITE_API_BASE_URL`, feature flags) |

## Required by environment

- **local**: `AETHER_ENV=local` only. (Backend runs fully in-memory.)
- **staging/production**: `JWT_SECRET`, `DATABASE_URL` (the app fails fast if
  missing), plus `BYOK_ENCRYPTION_KEY`, `ORACLE_SIGNER_PRIVATE_KEY`,
  `GRAFANA_ADMIN_PASSWORD` where those features are used.

## Feature-flagged / optional groups (default off)

Data quality (`AETHER_DATA_QUALITY_ENABLED`, `KYBER_INTELLIGENCE_QUALITY_ENABLED`),
external billing (`AETHER_EXTERNAL_BILLING_ENABLED`, `AETHER_STRIPE_BILLING_ENABLED`,
`KYBER_BILLING_PROVIDER_SYNC_ENABLED`, `BILLING_PROVIDER_MODE`), intelligence-graph
layers (`IG_*`), CIS (`CIS_ENABLED`), partner future flags
(`AETHER_PARTNER_ECOSYSTEM_ENABLED`, …), and (upcoming) connector flags
(`AETHER_CONNECTOR_*_ENABLED`) and demo (`DEMO_MODE`, `AETHER_DEMO_SEED_ENABLED`).
Their provider env vars (Stripe keys, connector credentials) are required **only
when the flag is on**.

## Frontend env modes

`VITE_AETHER_ENV` / `VITE_KYBER_ENV` / `VITE_DEMO_ENV` ∈
`local-mocked | local-live | staging | production`. `local-mocked` starts MSW
and requires no backend. Deployment uses env-driven `VITE_API_BASE_URL` — never
hardcode `localhost`.

The generated `docs/_generated/env.json` is the machine-readable index of
backend vars (regenerated by `make extract-docs`). See
[Secrets Management](SECRETS-MANAGEMENT.md) and
[Local Development](LOCAL-DEVELOPMENT.md).

## A6: Reward Enablement Variables

These variables configure the attribution-verified reward enablement system (A6).
In `local` mode all are optional and default to safe values with in-memory storage.
In `staging`/`production`, `REWARD_SIGNER_KEY_REF` or `ORACLE_SIGNER_KEY` is required
when the `onchain_claim` rail is enabled.

| Variable | Type | Default | Description |
|---|---|---|---|
| `REWARD_ENABLEMENT_ENABLED` | bool | `true` | Enable A6 reward enablement endpoints |
| `REWARD_REQUIRE_DURABLE_STORE` | bool | `false` (local), `true` (prod) | Fail if no DB available in non-local env |
| `REWARD_REQUIRE_ATTRIBUTION_DECISION` | bool | `false` | Require attribution_result_id on evaluate requests |
| `REWARD_REQUIRE_FRAUD_DECISION` | bool | `false` | Require fraud_decision_id on evaluate requests |
| `REWARD_REQUIRE_CONSENT_SNAPSHOT` | bool | `false` | Require consent_snapshot_id on evaluate requests |
| `REWARD_DEFAULT_EXECUTION_MODE` | string | `recommend_only` | Default rail mode when campaign has no rules |
| `REWARD_ALLOWED_RAILS` | string | (all) | Comma-separated list of allowed rails |
| `REWARD_WEBHOOK_TIMEOUT_MS` | int | `5000` | Timeout for tenant_webhook delivery HTTP calls |
| `REWARD_WEBHOOK_MAX_RETRIES` | int | `3` | Max retry attempts for webhook delivery |
| `REWARD_PROOF_EXPIRY_SECONDS` | int | `3600` | TTL for generated on-chain claim proofs |
| `REWARD_SIGNER_KEY_REF` | string | — | Key vault reference for oracle signer key (non-local) |
| `REWARD_DISABLE_LOCAL_SIGNER_IN_PROD` | bool | `true` | Block default Hardhat/Anvil test key in non-local envs |
| `REWARD_CONTRACT_REGISTRY_REQUIRED` | bool | `false` | Require contract registry entry for onchain_claim proofs |
| `EVM_REWARD_PROOFS_ENABLED` | bool | `true` | Enable EVM on-chain claim proof generation |
| `EVM_CHAIN_ID` | int | `1` | Default EVM chain ID for proof generation |
| `EVM_RPC_URL` | string | — | EVM RPC endpoint for receipt verification |
| `EVM_SIGNER_KEY_REF` | string | — | Key vault reference for EVM signer key |
| `EVM_CONTRACT_REGISTRY_REQUIRED` | bool | `false` | Require contract registry entry per chain for EVM proofs |
| `ORACLE_SIGNER_KEY` | string | Hardhat key (local only) | Raw EVM private key. **Never set in production.** Use `REWARD_SIGNER_KEY_REF` instead. |

## ML Serving Variables

These variables configure the ML serving layer. In `local` mode all are optional.
In `staging`/`production`, `ML_SERVICE_TOKEN` is **required** — the API returns 503 on
every request if it is absent.

| Variable | Type | Default | Description |
|---|---|---|---|
| `ML_SERVICE_TOKEN` | string | — | HMAC token for ML serving API service authentication. Required in `staging`/`production` — API returns 503 if absent. In `local`/`dev`, only validated if explicitly set. Generate with `openssl rand -hex 32`. |
| `AETHER_ENV` | string | `local` | Runtime environment: `local`, `staging`, or `production`. Governs fail-closed policies for ML serving (token enforcement, required-model readiness gate, synthetic/prod data handling). |
