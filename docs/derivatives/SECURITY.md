# Derivatives SECURITY

Derivatives Intelligence is a production bounded domain for read-only derivatives observations. PR1 defines canonical contracts, tenant-scoped storage foundations, consent governance, graph classification, and documentation that later PRs will extend with connectors, accounting, product workflows, and release gates.

See the source-of-truth derivatives documents under `docs/source-of-truth/` and the canonical TypeScript contracts in `packages/shared/derivatives.ts`.
